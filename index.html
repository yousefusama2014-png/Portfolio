04 — Featured Project

Factors that Fuel Student Performance

A SQL analysis in DataCamp DataLab digging into which habits — study time, sleep, attendance, tutoring — actually move the needle on exam scores.

SQL DataCamp DataLab Window Functions Aggregation

Given a student_performance table (attendance, study hours, sleep, tutoring sessions, teacher quality, exam score), I wrote a set of SQL queries to quantify what actually correlates with exam performance — not just eyeball it.

  • Used CASE WHEN logic to bucket students into study-hour ranges, then aggregated average exam scores per bucket to size the real gap between light and heavy studiers.
  • Filtered for students who both studied over 10 hours and participated in extracurriculars, to check whether outside commitments still let heavy studiers perform.
  • Built a DENSE_RANK() window-function query ranking every student by exam score, surfacing the attendance/sleep/tutoring profile shared by top performers.

Student Performance Query Explorer

avg_exam_score_by_hours_studied_range.sql

SELECT
  CASE
    WHEN hours_studied BETWEEN 1 AND 5  THEN '1-5 hours'
    WHEN hours_studied BETWEEN 6 AND 10 THEN '6-10 hours'
    WHEN hours_studied BETWEEN 11 AND 15 THEN '11-15 hours'
    ELSE '16+ hours'
  END AS hours_studied_range,
  AVG(exam_score) AS avg_exam_score
FROM student_performance
GROUP BY hours_studied_range
ORDER BY avg_exam_score DESC;
